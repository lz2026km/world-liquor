# 世界烈酒图鉴 v3.1.0

🍶 商业级深色主题 · 中华美食千百道团队出品

## 功能特点

- **200+款中外酒水** — 中国名酒 + 国际烈酒
- **四维筛选** — 香型/产区/酒精度/价格区间
- **四步品鉴** — 观色/闻香/尝味/定格
- **收藏导出** — localStorage持久化 + JSON下载
- **暗色模式** — 自动切换(23:00-06:00) + 手动切换
- **P1进阶功能** — 餐酒搭配、品鉴笔记、成就系统、雷达图
- **随机轮播** — 顶部大卡片推荐
- **响应式布局** — 移动端/平板/桌面
